# Scarface Skin Selector
Mod to add new player skins to Scarface: The World Is Yours on PC

# Usage
Drop SkinSelector.asi and SkinSelector.ini into your Scarface root folder. You will need an ASI Loader!

You can edit the .ini file with your text editor of choice to set up the keys to change characters in-game. By default, F55-F6 switches between vanilla characters and F7-F8 switches between addon characters.
